# NVR App

Самописный NVR (Network Video Recorder) с непрерывной записью и возможностью скачать любой произвольный фрагмент **без перекодирования**.

## Возможности

- Авторизация (JWT)
- Сетка превью камер с обновлением каждые 10 секунд
- Прямой эфир (HLS) с зумом колёсиком мыши; H.264 и H.265/HEVC
- Непрерывная запись в MP4 с копированием исходных аудио- и видеопотоков (`-c copy`), без перекодирования
- Экспорт любого временного фрагмента через `ffmpeg -c copy` (без перекодирования)
- H.265 воспроизводится в браузерах и на устройствах с поддержкой HEVC; Safari использует нативный HLS, для остальных браузеров применяется hls.js и проверка поддержки кодека
- Добавление / удаление камер
- Старт / стоп записи

> Страница «Архив» пока заглушка — будет реализована следующей итерацией.

## Быстрый старт

### Требования
- Docker + Docker Compose
- Node.js 18+

### Запуск

```bash
# 1. Backend + MediaMTX
cd deploy
docker compose up -d --build

# 2. Frontend
cd ../frontend
npm install
npm run dev
```

Открыть: **http://localhost:5173**

Логин по умолчанию: `admin` / `admin`

## API (кратко)

| Метод | Путь                          | Описание                    |
|-------|-------------------------------|-----------------------------|
| POST  | `/api/login`                  | Авторизация                 |
| GET   | `/api/cameras`                | Список камер + статусы      |
| POST  | `/api/cameras`                | Добавить камеру             |
| DELETE| `/api/cameras/:id`            | Удалить камеру              |
| POST  | `/api/cameras/:id/record/start` | Начать запись             |
| POST  | `/api/cameras/:id/record/stop`  | Остановить запись         |
| POST  | `/api/export`                 | Вырезать фрагмент (скачать) |
| GET   | `/api/previews/:id.jpg`       | Превью-кадр                 |

## Поддержка видеокодеков

- **H.264/AVC** — приём, HLS-просмотр и запись без перекодирования.
- **H.265/HEVC** — приём, fMP4 HLS-просмотр и запись без перекодирования.
- FFmpeg использует `-c copy`; он не преобразует H.265 в H.264.
- Для превью главной страницы FFmpeg декодирует один кадр и сохраняет уменьшенный JPEG. Это отдельная миниатюра, а не перекодирование основного потока.
- Возможность воспроизведения H.265 зависит от браузера, ОС и аппаратного декодера. Если HEVC недоступен, запись всё равно сохраняется; для просмотра используйте совместимое устройство/браузер.

## Как работает запись и экспорт

- Запись идёт **непрерывно** в MP4-файл (один файл на сутки или с суффиксом времени).
- При экспорте фрагмента вызывается:

```bash
ffmpeg -ss <start> -to <end> -i recording.mp4 -c copy -avoid_negative_ts make_zero out.mp4
```

То есть **без перекодирования**.
